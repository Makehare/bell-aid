Was beim Aufruf dieser Seite passiert

Diese Seite wird über GitHub Pages bereitgestellt, einen Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA (in Europa: GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Niederlande). Beim Aufruf überträgt Ihr Browser technisch notwendige Daten an die Server von GitHub, insbesondere Ihre IP-Adresse sowie Datum und Uhrzeit des Abrufs. GitHub speichert nach eigenen Angaben die IP-Adresse der Besucher von GitHub-Pages-Seiten zu Sicherheitszwecken. Wir selbst erhalten diese Daten nicht. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Wie lange GitHub diese Daten speichert, richtet sich nach dem Zweck und gesetzlichen Pflichten. Einzelheiten: Datenschutzerklärung von GitHub

Übermittlung in die USA

GitHub verarbeitet Daten auch in den USA. GitHub ist nach dem EU-US Data Privacy Framework zertifiziert (https://www.dataprivacyframework.gov/list). Für die Übermittlung besteht damit ein Angemessenheitsbeschluss der EU-Kommission (Art. 45 DSGVO).

Keine Cookies, kein Tracking

Diese Seite setzt keine Cookies, speichert nichts in Ihrem Browser, nutzt keine Analyse- oder Tracking-Dienste und lädt keine Inhalte von anderen Anbietern. Schriften und Programmcode kommen von derselben Seite.

Das Update selbst

Die Firmware wird von dieser Seite geladen und in Ihrem Browser über die USB-Verbindung (Web Serial) direkt auf Ihr Bell-Aid-Gerät geschrieben. Dabei werden keine Daten über Sie, Ihren Computer oder Ihr Gerät an uns oder an Dritte gesendet. Wenn Sie im Installationsfenster einen Link zu einer anderen Website anklicken (z. B. für Treiber), gelten dort deren Datenschutzhinweise.

Pflicht zur Bereitstellung, automatisierte Entscheidungen

Sie sind nicht verpflichtet, Daten bereitzustellen. Ohne die Übertragung der IP-Adresse kann die Seite aber technisch nicht aufgerufen werden. Eine automatisierte Entscheidungsfindung nach Art. 22 DSGVO findet nicht statt.

Ihre Rechte

Sie haben das Recht auf Auskunft (Art. 15 DSGVO), Berichtigung (Art. 16), Löschung (Art. 17), Einschränkung der Verarbeitung (Art. 18) und Datenübertragbarkeit (Art. 20). Eine E-Mail an request@makehare.com genügt. Für die bei GitHub gespeicherten Daten können Sie sich auch direkt an GitHub wenden (privacy@github.com).

Widerspruchsrecht

Sie können der Verarbeitung nach Art. 6 Abs. 1 lit. f DSGVO aus Gründen, die sich aus Ihrer besonderen Situation ergeben, jederzeit widersprechen (Art. 21 Abs. 1 DSGVO).

Beschwerderecht
