# Fab package: DBN-MAIN rev A (JLCPCB)

Generated by `bash gen/build.sh fab` (gen/fab.py) from the DRC-clean board.

| File | Use |
|------|-----|
| dbn-main_gerbers.zip | JLCPCB PCB upload (Gerbers + Excellon drill, PTH+NPTH merged). Origin = board top-left corner, same as the CPL |
| bom_jlc.csv | JLC assembly BOM (Comment, Designator, Footprint, LCSC Part #). Universal population, DNP excluded (R8) |
| cpl_jlc.csv | JLC pick-and-place. Origin = board top-left corner, mm, KiCad rotations (Y is negative = down) |
| bom_full.csv | All parts incl. DNP, with MPN |
| dbn-main.step | Board + all parts. Origin = board top-left (front view); STEP +X right, +Y UP (board spans y 0..-82), front face at z=+1.6 |
| dbn-main_board_only.step | Bare board (outline + holes) |
| gerbers/ | Individual layers, drill map PDF, job file |

Origin check: gen/fab.py fails the build unless the Edge.Cuts Gerber starts at (0,0) and every drill hole and CPL part lies inside the outline (fixes the JLC "parts not on the board" error from the first upload).

Order settings: 2 layers, 1.6 mm FR4, 1 oz, 50 x 82 mm, any colour, HASL or ENIG.
Assembly: top side only. The ICS-43434 (U4) is listed as "Standard PCBA only" at JLC.
Check part rotations in JLC's DFM/placement preview before confirming (KiCad vs JLC rotation offsets).

Fab constraints used in dbn-main.kicad_dru:
- min track 0.15 mm
- clearance 0.2 mm
- via 0.6/0.3 mm
- hole-to-hole 0.5 mm
- copper-to-edge 0.5 mm

All of these are within JLC 2-layer standard capability.
